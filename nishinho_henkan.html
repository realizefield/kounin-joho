n進法の考え方 — 10進法・2進法・3進法のしくみ
★★★
💬 たとえ：「いくつ集まったら次の位に繰り上がるか」が進法の違いです。10進法は10個、2進法は2個、3進法は3個集まると次の位へ上がります。

私たちが日常で使っている数は 10進法 です。「1が10個で10、10が10個で100…」というしくみです。コンピュータは電気のON（1）とOFF（0）しかわからないため 2進法 を使います。

📝 ここが試験に出ます ★★★
n進法=n個集まると次の位に繰り上がる数の数え方です。
2進法は「0と1の2種類」しか使いません。コンピュータはこの2進法を使っています。
2進数の「10」は10進数の「2」、2進数の「100」は10進数の「4」です。
n進数は右下に(n)を書いて区別します（例：1101(2)、1234(5)）。

10進数 → n進数への変換（÷nの筆算）
★★★
💬 たとえ：10進数をn進数に変換するには「nで割り続けて余りを下から読む」方法が確実です。テキストの例題を使って手順を確認しましょう。
1
変換したい10進数をnで割り、商と余りを書きます。
2
商がまだnより大きければ、さらにnで割り続けます。
3
商が0になるまで繰り返します。
4
余りを下から順に読むとn進数になります（最後の商も最上位の桁）。

2 ）13 2 ） 6 …1 ↑ 2 ） 3 …0 ↑ 2 ） 1 …1 ↑ 0 …1 ↑ ▲下から読む
▶ 余りを下から読むと 1101
答え：1101(2)
② 23(10) → 3進数
3 ）23 3 ） 7 …2 ↑ 3 ） 2 …1 ↑ 0 …2 ↑ ▲下から読む
▶ 余りを下から読むと 212
答え：212(3)
③ 37(10) → 5進数
5 ）37 5 ） 7 …2 ↑ 5 ） 1 …2 ↑ 0 …1 ↑ ▲下から読む
▶ 余りを下から読むと 122
答え：122(5)
④ 194(10) → 5進数（テキスト例）
5 ）194 5 ） 38 …4 ↑ 5 ） 7 …3 ↑ 5 ） 1 …2 ↑ 0 …1 ↑ ▲下から読む
▶ 余りを下から読むと 1234
答え：1234(5)（「イチニサンシ」）
⚠ よくある間違い：余りを「上から」読んでしまうミスが多いです。必ず下から読みます！
📝 ここが試験に出ます ★★★
10進数 → n進数の変換=「nで割り続けて余りを下から読む」。
商が0になるまで割り続けます。途中でやめてはいけません。
n進数は右下に(n)を書いて10進数と区別します（例：1101(2)）。

n進数 → 10進数への変換（位の重みで計算）
★★★
💬 たとえ：n進数を10進数に変換するには「各桁の数字 × その位の重み」をすべて足し算します。お金の計算と同じです。1000円札が何枚・100円玉が何枚…という計算に似ています。

n進数の各桁に「位の重み（nの累乗）」を掛けて合計します。

③ 1011(2) → 10進数
1×2³ + 0×2² + 1×2 + 1×1 = 8 + 0 + 2 + 1 = 11

④ 1201(3) → 10進数
1×3³ + 2×3² + 0×3 + 1×1 = 27 + 18 + 0 + 1 = 46
📝 ここが試験に出ます ★★★
n進数 → 10進数の変換=「各桁 × 位の重み（nの累乗）」の合計です。
2進数の位の重みは右から 2⁰=1、2¹=2、2²=4、2³=8、2⁴=16…
「1の立っている位の重みだけ足す」と速く計算できます。
5進数の位の重みは右から 1、5、25、125、625…（5の累乗）です。

8進数・16進数との変換
★★
💬 たとえ：2進数は桁数が多くなって読みにくいので、3桁ずつまとめると8進数、4桁ずつまとめると16進数に変換できます。
2進数 ↔ 8進数（3桁ずつ）
2進数を右から3桁ずつ区切り、各3桁を8進数1桁に変換します。

例：101 110(2)
101(2)=5、110(2)=6
→ 56(8)
2進数 ↔ 16進数（4桁ずつ）
2進数を右から4桁ずつ区切り、各4桁を16進数1桁に変換します。

例：1010 1111(2)
1010(2)=10=A、1111(2)=15=F
→ AF(16)

🔢 例題：16進数の変換（3パターン）
① 2進数 → 16進数（4桁ずつまとめる）
10101111(2) を16進数に変換する 右から4桁ずつ区切る 1010 | 1111 1010(2) = 1×8+0×4+1×2+0 = 10 = A 1111(2) = 1×8+1×4+1×2+1 = 15 = F 答え：AF(16)
② 16進数 → 2進数（4桁に展開）
B4(16) を2進数に変換する 各桁を2進数4桁に展開する B = 11(10) = 1011 4 = 4(10) = 0100 答え：10110100(2)
③ 10進数 → 16進数（÷16の筆算）
175(10) を16進数に変換する 16 ）175 16 ） 10 …15 = F ↑ 0 …10 = A ↑ 余りを下から読むと A, F 答え：AF(16)
🔙 10進数175=16×10+15=AF(16)
余りが10以上の場合はA〜Fに変換します。
④ 16進数 → 10進数（位の重みで計算）
3C(16) を10進数に変換する 3 × 16¹ + C × 16⁰ = 3 × 16 + 12 × 1 = 48 + 12 = 60 答え：60(10)
🔙 C=12 なので 12×1=12。
16進数の各桁の重みは右から 1・16・256…
🔙 まとめ：16進数変換の3パターン
① 2進数→16進数：右から4桁ずつまとめて各4桁を16進1桁に変換します。
② 16進数→2進数：各桁を2進数4桁に展開します。
③ 10進数→16進数：16で割り続けて余りを下から読みます（余り10以上はA〜Fに変換）。
📝 ここが試験に出ます ★★
2進数↔8進数=3桁ずつまとめる（または分解する）。
2進数↔16進数=4桁ずつまとめる（または分解する）。
16進数では10=A、11=B、12=C、13=D、14=E、15=Fと表します。
10進数→16進数=16で割り続けて余りを下から読みます。余りが10以上のときはA〜Fに変換します。
16進数の位の重みは右から 16⁰=1、16¹=16、16²=256 です。
