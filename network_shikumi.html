インターネットの仕組み　—　IP・DNS・URL
★★★
💬 たとえ：インターネット上のすべてのコンピュータには「住所番号（IPアドレス）」がついています。人名は覚えやすいのに住所番号は覚えにくいですが、「電話帳（DNS）」があれば名前から番号を調べられます。URLとドメイン名はちょうど人の名前にあたります。

インターネットに接続されたすべての機器には IPアドレス という固有の番号が割り当てられています。しかし数字の羅列は覚えにくいため、人間が覚えやすい名前として ドメイン名 を使います。この変換を担うのが DNS（ドメインネームシステム） です。

Webページの住所を表す文字列を URL といいます。URLの構成を覚えましょう。

URL の構成例：
https://www.mext.go.jp/index.html

https://スキーム（通信方式。httpsはSSL暗号化あり）
www.mext.go.jpドメイン名（サーバの名前。go.jp=日本の政府機関）
/index.htmlパス（サーバ内のファイルの場所）
📝 ここが試験に出ます ★★★
IPアドレス=インターネット上の機器の住所番号です。
DNS=ドメイン名をIPアドレスに変換するしくみです（「インターネットの電話帳」）。
URL=Webページの場所を示す文字列です（スキーム+ドメイン名+パス）。
ドメイン名の「.jp」は日本、「.com」は商業組織、「.go.jp」は日本の政府機関を表します。
2
Webページが表示されるまで　—　HTTP・HTTPS・パケット
★★★
💬 たとえ：インターネットでデータを送るとき、大きなデータをそのままでは送れません。手紙を分割して複数の封筒（パケット）に入れて送り、相手が受け取ったら順番に並べ直すイメージです。
🔒 HTTP と HTTPS
  • HTTP=Webの通信ルール（暗号化なし）
  • HTTPS=SSL暗号化あり（安全）
  • URLが「http://」=🔓危険
  • URLが「https://」=🔒安全
📩 パケット通信
  • データを小分けにして送ります
  • 異なる経路で同時に送れます
  • 届いた後に順番を組み立てます
  • 通信が効率的になります

インターネットの通信では プロトコル というルールを使います。通信の階層を定めたモデルとして TCP/IP が広く使われています。

📝 ここが試験に出ます ★★★
HTTP=Webの通信ルール（暗号化なし）。HTTPS=SSL暗号化あり（安全）。
パケット=データを小分けにした「小包」。インターネットはパケット通信で効率よく送受信します。
プロトコル=通信のルール・取り決め。同じプロトコルなら異なる機器同士でも通信できます。
TCP/IP=インターネット通信の基本となるプロトコルの組み合わせです。
3
メールの仕組み　—　SMTP・POP・IMAP
★★★
💬 たとえ：メールの仕組みは「郵便」と同じです。差出人が郵便ポスト（SMTPサーバ）に投函し、郵便局（メールサーバ）で保管され、受取人が郵便受けから取り出します（POP/IMAP）。

プロトコル正式名称役割たとえ
SMTP Simple Mail Transfer Protocol メールの送信に使います 郵便ポストに投函するイメージ
POP Post Office Protocol メールをサーバからダウンロードします（サーバから削除） 郵便受けから手紙を取り出すイメージ
IMAP Internet Message Access Protocol サーバにメールを残したまま確認します コンビニの宅配ボックスのイメージ（何度でも確認可）
POP の特徴
  • ダウンロード後サーバから削除
  • オフラインでも読める
  • 1台の端末向き
IMAP の特徴（現在主流）
  • サーバにメールが残る
  • スマホ・PC など複数端末で同期
  • GmailやYahoo!メールはIMAP

メールアドレスの構成も覚えましょう。 taro@example.co.jp →「taro」がユーザ名、「@」の後ろ「example.co.jp」がドメイン名（メールサーバの住所）です。

📝 ここが試験に出ます ★★★
SMTP=メールの送信に使うプロトコルです。
POP=メールをダウンロードして削除するプロトコルです（1台向き）。
IMAP=メールをサーバに残したまま確認するプロトコルです（複数端末向き・現在主流）。
メールアドレスは「ユーザ名@ドメイン名」の形式です。
4
無線LANの仕組み　—　SSID・WPA・ルータ
★★★
💬 たとえ：無線LANは「見えないケーブル」でインターネットに繋ぐしくみです。Wi-Fiのアクセスポイントが「電波の発信基地」で、SSID はそのネットワークの「名前」です。パスワードで不正接続を防ぎます。
📶 SSID　とは
  • 無線LANネットワークの「名前」
  • Wi-Fi設定画面に表示される
  • 同じSSIDのネットワークに接続
  • セキュリティのため非表示設定も可能
🔒 WPA2・WPA3（暗号化）
  • 無線LAN通信の暗号化規格
  • WPA3が現在の最新規格
  • 接続時のパスワードで守る
  • 古い規格（WEP）は危険

家庭内ネットワークの機器も覚えましょう。

機器名役割たとえ
ルータネットワーク同士をつなぎ、データを適切な宛先に転送します郵便局の仕分け係
アクセスポイント無線LANの電波を発信する基地局ですWi-Fiの発信基地
ハブ（スイッチ）複数の有線LAN機器を束ねてつなぎますタコ足配線の延長コード
DHCPサーバネットワークに接続した機器にIPアドレスを自動で割り当てます宿泊者に自動で部屋番号を割り当てるホテル
⚠ 公衆無線LAN（フリーWi-Fi）の危険性
カフェや駅などのフリーWi-Fiは暗号化されていない場合があります。同じネットワーク上の悪意ある第三者に通信内容を盗まれる（盗聴）リスクがあります。利用する際はHTTPSのサイトのみ使用し、重要な情報の入力は避けましょう。
📝 ここが試験に出ます ★★★
SSID=無線LANネットワークの「名前」です。Wi-Fi設定画面に表示されます。
WPA2・WPA3=無線LANの暗号化規格です（WPA3が最新）。
ルータ=ネットワーク同士をつなぎ、データを転送する機器です。
フリーWi-Fiは盗聴リスクがあります。HTTPSサイト以外で個人情報を入力してはいけません。

🧩 この章のつながり
インターネット通信はすべて「プロトコル（ルール）」に従って行われます。Webページを見るときはHTTP/HTTPS、メールを送るときはSMTP、受け取るときはPOP/IMAPを使います。これらのデータはすべてパケットに分割されてIPアドレスを手がかりにDNSの助けを借りて届けられます。第3章で学んだ「SSL・暗号化」も、このネットワーク上の通信を安全にする技術です。
